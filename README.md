# Koksharov.com

Minimal personal website for Grigorii Koksharov (Grisha), Real Estate Finance Systems · SectorLumen Ltd.

The site is plain HTML and CSS. Edit `index.html` for English and `kr/index.html`
for Korean. Both pages use `assets/site.css`; the portrait is also in `assets/`.
GitHub Pages publishes the root of the default branch.

The Korean page is available at `/kr/` (and `/kr` redirects there). It is unlinked
from the English page and includes `noindex`. It is public, not access-controlled.
Keep factual updates synchronized across both languages.

For a local preview, run `python3 -m http.server 4318` in this directory and open
http://localhost:4318.

The desktop layout fits a typical laptop viewport. Mobile and enlarged text use natural scrolling, without hiding any content.
