# Koksharov.com

Minimal personal website for Grisha Koksharov, Real Estate Finance Systems · SectorLumen Ltd.

The site is plain HTML and CSS. Edit `index.html`; the portrait is in `assets/`.
GitHub Pages publishes the root of the default branch.

For a local preview, run `python3 -m http.server 4318` in this directory and open
http://localhost:4318.

The desktop layout fits a typical laptop viewport. Mobile and enlarged text use natural scrolling, without hiding any content.
